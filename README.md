### 🚀 Sobre Mí

Lidero la dirección estratégica y técnica en **AventoAI S.A.S.**, diseñando soluciones propietarias de software de alto rendimiento, agentes de Inteligencia Artificial para empresas y arquitecturas B2B de misión crítica.

- 💼 **Actualmente:** Dirigiendo el roadmap tecnológico, infraestructura y despliegue de soluciones inteligentes en **AventoAI**.
- 🛠️ **Foco de Arquitectura:** Sistemas reactivos, agentes autónomos, microservicios orientados a eventos y flujos de automatización de ultra-baja latencia.
- 🧪 **Cultura de Calidad:** Rigor en QA (automatización Cypress, pruebas de carga con k6, observabilidad y rendimiento Core Web Vitals).
- 📍 **Ubicación:** Colombia 🇨🇴 (disponible para alianzas estratégicas y desafíos globales).
